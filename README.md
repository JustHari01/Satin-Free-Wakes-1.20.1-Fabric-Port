# Satin Free Wakes (Unofficial 1.20.1 Port)

An unofficial Fabric backport of [Satin Free Wakes](https://modrinth.com/mod/satin-free-wakes) to Minecraft 1.20.1. This project is based on the [Commander07/wakes](https://github.com/Commander07/wakes) source fork, which in turn builds on [Goby56/wakes](https://github.com/Goby56/wakes). It is not an official release and is not endorsed by those authors.

The mod adds simulated water wakes behind moving entities and rowing boats, splash effects, and water spray at speed. It does not require Satin. The configuration screen is available when Mod Menu and YetAnotherConfigLib are installed; both are optional.

## Requirements

- Minecraft 1.20.1
- Fabric Loader 0.14.21 or newer
- Fabric API
- Java 17 or newer

Optional: Mod Menu and YetAnotherConfigLib 3.x for the configuration screen.

## Source and build

The complete source for this backport is available in this repository and as the source archive attached to each release. This project is licensed under GPL-3.0-only; see [LICENSE](LICENSE) and [PORTING.md](PORTING.md) for the license, upstream revisions, and compatibility changes made for 1.20.1.

To build the mod, run `./gradlew build` with Java 17 or newer.
